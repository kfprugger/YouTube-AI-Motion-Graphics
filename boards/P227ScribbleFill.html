Colour it in, like a marker

Scribble fill

For a chart or shape that gets "coloured in". Outlines first, then a thick zig-zag marker stroke fills each bar from left to right, one after another, clipped to its shape. Reads hand-made and warm. Works on any shape: bars, boxes, map regions, icons.
Example values.

tl.from(fills, {drawSVG: 0, duration: 1.4, ease: "power2.inOut", stagger: 1.2}, t) // each fill is a zig-zag path inside a clipPath
